# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of nlpaug.

| Version | Supported |
| --- | --- |
| 2.0.x | Yes |
| Earlier versions | No |

## Reporting a Vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting feature on the repository's Security page. Do not open a public issue
or disclose proof-of-concept details before a fix is available.

Include the affected version, impact, reproduction steps, and any proposed fix.
We will acknowledge the report, assess its severity, coordinate a release, and
credit the reporter if they would like to be named.
